# Move Strong PWA

Upload all files and folders in this package to the root of your GitHub Pages repository:

- index.html
- manifest.webmanifest
- sw.js
- icons/

Then wait for GitHub Pages to redeploy.

Open the GitHub Pages URL in Chrome. Use either the in-app **Install App** button or Chrome's menu:
**Add to Home screen** / **Install app**.

Important: Keep the `icons` folder and the two files `manifest.webmanifest` and `sw.js` in the repository root beside `index.html`.
